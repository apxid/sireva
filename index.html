Selamat Datang!

Setup awal data kelas dan nama siswa. Satu kelas = satu sheet di spreadsheet.

ℹ️ Pengaturan Nilai (KKTP, Nilai Terendah, Nilai Tertinggi):
  • KKTP = Kriteria Ketuntasan Tujuan Pembelajaran (default 75). Siswa dengan NA ≥ KKTP dianggap tuntas.
  • Nilai Terendah = batas bawah nilai rapor (default 79). Siswa dengan NA terendah akan dapat nilai rapor = Nilai Terendah.
  • Nilai Tertinggi = batas atas nilai rapor (default 94). Siswa dengan NA tertinggi akan dapat nilai rapor = Nilai Tertinggi.
  • KKTP ≠ Nilai Terendah — ketiganya diatur di sheet config (kolom E-G: key | value | keterangan). Edit langsung di Google Sheets untuk mengubah.
  • Formula Rapor: ((NA − Nilai Terendah)/(Nilai Tertinggi − Nilai Terendah)) × (Nilai Tertinggi − Nilai Terendah) + Nilai Terendah
